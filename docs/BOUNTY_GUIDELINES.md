# Bounties and Issues Guidelines

## Overview
This document outlines the bounty program and issue management guidelines for S.P.L.U.R.T.

## Bounty Program

### Eligibility
- Anyone can claim a bounty (no prior contribution required)
- One bounty per person at a time (unless stated otherwise)
- Must use the correct claim format

### Bounty Types
| Type | Reward | Time Limit |
|------|--------|-----------|
| Bug Fix | 50-500 points | 7 days |
| Feature | 100-1000 points | 14 days |
| Sprites/Art | 50-300 points | 7 days |
| Mapping | 100-500 points | 10 days |
| Sound/Music | 50-200 points | 7 days |
| Documentation | 25-100 points | 5 days |

### Claiming a Bounty
1. Find an issue labeled `bounty`
2. Comment: "Claiming this bounty" with your Discord handle
3. Wait for assignment confirmation
4. Complete the work within the time limit
5. Submit a PR referencing the bounty issue
6. PR merged = bounty paid

### Issue Labels
| Label | Meaning |
|-------|---------|
| `bounty` | Has a reward attached |
| `bounty: easy` | Good for newcomers |
| `bounty: medium` | Moderate difficulty |
| `bounty: hard` | Complex task |
| `claimed` | Someone is working on it |
| `in progress` | Work is underway |

### Rules
- No AI-generated sprite submissions
- Test your changes locally before PR
- Follow code style guidelines
- One PR per bounty
- Don't claim if you can't finish in time

### Payment
- Points tracked in Discord
- Redeemable for in-game perks
- Top contributors get special roles
